# Glossary of poker terms

Terms are defined here the first time they are needed, for readers with no poker background.

- **Heads-up**: a game with exactly two players.
- **Bluff**: betting with a hand that would lose if called.
- **Bluff-catcher**: a hand that only beats a bluff.
- **Nuts**: the best possible hand in the situation.
- **Air**: a hand with no showdown value.
- **GTO (game-theory optimal)**: a Nash equilibrium strategy; it cannot be exploited.
